## Level editor (Oct 10)

- **Oct 10 — PROPOSED, pending Jack's approval:** the level and script editor design: `/editor` on Vercel (Jack only, an `editors` allowlist and a separate `EditorCtx` and Postgres role, so it never touches child data), `level/0.1` JSON per level, React Flow in a separate bundle (the game bundle doesn't grow), autosaved drafts, atomic publish with `level_revisions` and rollback, the game loading published levels from `/api/v1/levels/*` with CDN and IndexedDB caching, and a 7-phase rollout in which graph becomes the Vercel default only after the editor exists. Nothing is built until Jack approves. [tech/level-editor.md](tech/level-editor.md)
- **Oct 10 — Decided (Jack): a level is its own zone.** Zones are dropped from the schema and the editor (there is no zone layer). Each level has one `settings` block: title, backdrop, music, word pool and tier, enemies and packs, the optional location boss, and the unlock order. Today's zones map onto levels by Desy's table; bosses, unlocks and `zonesDefeated` become boss level ids (one-time save migration). Desy's realm_1 split into 3 levels is **proposed, pending Jack**. [tech/level-editor.md §2.4](tech/level-editor.md#24-per-map-settings-and-the-boss), [design/level-json-coverage.md §3.9](design/level-json-coverage.md)
- **Oct 10 — Decided (Jack): the source of truth for level content.** The DB is the live source of level content made or edited in the editor, and the DB wins. The editor and backend have **no GitHub write access** (no GitHub App, no token, no Action that commits). **GameDev exports** every published release from its own box (a read-only, editor-authenticated export endpoint plus a token kept only on that box) into `docs/data/levels/<id>.json`, runs the validators, and commits and pushes with gh as Jack, so git keeps the history and a backup. The repo copy also serves as the seed and for disaster recovery, and CI validators and the sim read it. Repo edits reach the DB only through a deliberate import. This **revises the Oct 9 "GitHub is the only primary source" rule for level content only**; docs, code, schemas and every other table stay GitHub-primary. [tech/level-editor.md §9](tech/level-editor.md#9-source-of-truth-db-live-repo-backups-by-gamedev-on-request)
